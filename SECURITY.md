# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.**

Report privately in either of these ways:

- **GitHub private vulnerability reporting:** open the affected repository's **Security** tab and choose **Report a vulnerability**.
- **Email:** security@krakenkey.io

Please include:

1. A description of the vulnerability and its impact
2. Steps to reproduce, or a proof of concept
3. Affected component and version
4. A suggested fix, if you have one

## Response timeline

- **Acknowledgment:** within 48 hours
- **Initial assessment:** within 5 business days
- **Fix:** depends on severity, typically within 30 days

## Scope

- The managed service at krakenkey.io, its API and dashboard
- Code in the public KrakenKey repositories: app, cli, probe, connector, cert-action, terraform-provider-krakenkey and their releases and packages

Out of scope:

- Third-party services (Let's Encrypt, DNS providers, cloud providers)
- Social engineering
- Denial of service

## Supported versions

Only the latest release of each component receives security fixes.

## Acknowledgments

We're glad to credit researchers who report valid vulnerabilities, with your permission.
